# Portfolio Website

Personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion. Features a dark-first, fluid glassmorphic UI showcasing software engineering experience, distributed systems research, and quantitative/ML projects.

Live site: [pf-website-seven.vercel.app](https://pf-website-seven.vercel.app/)

## Tech Stack

- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Animations: Framer Motion
- Icons: Lucide React
- Deployment: Vercel

## Key Sections

- Hero: Bio, current focus, and contact links
- Experience: Roles at Cincinnati Insurance, The Data Mine (Feenix Group), Prof. Datta's Lab, and Fifth Third Bank
- Featured Projects: Graph Neural Network Options Pricing Engine, Real-Time Campus Delivery Platform
- Technical Arsenal: Core languages, distributed systems, databases, and Purdue coursework
- Beyond the Terminal: Personal interests and engineering pursuits outside software
